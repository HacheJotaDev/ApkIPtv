# XTREAM IPTV

Reproductor IPTV basado en Xtream Codes API - Sin VIP, Sin Anuncios.

## Características

- TV en Vivo con categorías
- Películas (VOD) con detalles
- Series con temporadas y episodios
- Soporte para Xtream Codes API y listas M3U
- Reproductor de video integrado
- Búsqueda de contenido
- Sin anuncios, sin restricciones VIP
- Interfaz oscura moderna

## Conexión

### Xtream Codes
Ingresa tu servidor, usuario y contraseña de tu servicio IPTV.

### Lista M3U
Pega la URL de tu lista M3U para cargar los canales y películas.

## Compilación

```bash
flutter pub get
flutter build apk --release
```

El APK se generará en `build/app/outputs/flutter-apk/app-release.apk`
